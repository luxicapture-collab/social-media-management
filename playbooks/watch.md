# Daily watch playbook

Check what changed since the last run and only file what affects the work.

## Sources

- Platforms: Meta Graph API and Instagram Platform changelogs, Instagram/Facebook creator news,
  LinkedIn Marketing API recent changes, X developer changelog.
- Tools: Higgsfield (new or retired models, price changes), ElevenLabs changelog, Metricool.
- Client accounts: disconnected networks, expiring tokens, failed or stuck posts, sudden drops
  (followers −2 % day-on-day, reach −40 % week-on-week), goals behind pace.
- Credits: Higgsfield balance and ElevenLabs characters vs this week's approved quotes.

## Importance

- **high** — something breaks or needs Morteza within days: API/posting change that affects us,
  disconnected account, token expiring within 7 days, failed post, goal off track, credits that
  can't cover approved work.
- **medium** — a change worth using: new format, model or feature that serves a client goal.
- **info** — context only. Skip general industry news.

Each alert: source, title, two plain sentences, the action to take, and the link.

## Self-update

When a change alters how the agent should work (a new caption limit, a new format, a retired
metric), propose an addition to the relevant playbook. Morteza approves it on the Alerts
screen; approved text is appended to the playbook and used from the next run.
